# Pet Management System 🐾

## 📌 Description

A console-based Pet Management System developed in C++ that allows users to manage pet records efficiently.

## ⚙️ How It Works

The system provides a menu-driven interface where users can perform different operations on pet records. Each pet has associated details such as owner information, health records, and vaccination data. The system stores all data in a file, allowing information to persist even after the program is closed.

Users can:

* Add new pet records with complete details
* View all stored pets
* Search pets by name or ID
* Update existing records
* Delete records when needed

All operations are handled using structured data and file handling to ensure organized and persistent storage.

## 🚀 Features

* Add new pet records
* Display all pets
* Search pet by name or ID
* Update pet details
* Delete pet records
* File handling for data persistence
